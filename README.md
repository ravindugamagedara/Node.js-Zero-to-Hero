# Node.js & Express.js MongoDB API

A basic RESTful API setup built with **Node.js**, **Express.js**, and **MongoDB (Mongoose)**. This repository demonstrates how to configure an Express server, safely connect to a MongoDB database using `dotenv`, and structure a backend application.

## 🚀 Features

- **Express Server Setup**: Basic routing and server configuration.
- **Database Integration**: MongoDB connection via Mongoose ODM.
- **Environment Variables**: Secure credential handling using `dotenv`.
- **Live Reloading**: Automated server restarts during development with `nodemon`.

## 🛠️ Tech Stack

- **Node.js**: JavaScript Runtime Environment
- **Express.js**: Web Framework for Node.js
- **MongoDB**: NoSQL Database
- **Mongoose**: Object Data Modeling (ODM) library for MongoDB & Node.js
- **dotenv**: Environment variable management
